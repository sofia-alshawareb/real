## 1. Введение

Веб-приложение для классификации руды по панорамным
оптическим (OM) изображениям полированных шлифов. Приложение помогает:

- загружать панорамы шлифов и объединять их в эксперименты;
- получать автоматическую сегментацию изображения на классы (обычные и
  тонкие сульфидные срастания, тальк, нерудная матрица) — либо от серверной
  ML-модели, либо в демо-режиме имитации;
- вручную проверять и корректировать разметку прямо в браузере;
- классифицировать кадры по типу руды (рядовая, труднообогатимая,
  оталькованная) на основе рассчитанных долей классов;
- вести справочник месторождений с профилями минералов и порогами талька;
- формировать и выгружать отчёты (PDF, CSV) по результатам экспериментов;
- отслеживать статистику по всем экспериментам на общем дашборде.

Приложение — **прототип**: все данные (эксперименты, месторождения, маски)
хранятся локально в браузере пользователя (IndexedDB), а не на общем
сервере. Это значит, что данные не синхронизируются между разными
компьютерами и браузерами и могут быть потеряны при очистке данных сайта.

## 2. Начало работы

### 2.1. Адрес приложения

Приложение открывается в браузере по адресу, который сообщит администратор
или инженер, запустивший сервис (обычно `http://localhost:5173` — при
локальном запуске, или адрес во внутренней сети/временная публичная
ссылка).

### 2.2. Верхняя панель

В верхней части экрана расположены:

- **Название и логотип** сервиса.
- **Поле «Автор»** — впишите своё имя. Оно используется при создании
  экспериментов, записях в истории и блокировке одновременного
  редактирования.
- **Переключатель «Демо: локальная имитация ML»**:
  - **включён** — сегментация считается локально в браузере, без
    обращения к серверу (подходит для демонстрации без backend);
  - **выключен** — сегментация выполняется настоящим ML-сервером
    (нужен запущенный backend). Подробнее см. раздел
    [10. Демо-режим и серверный ML](#10-демо-режим-и-серверный-ml).
  - Значок «i» рядом с переключателем показывает подсказку с текущим
    состоянием при наведении.
- **Меню (три точки)** справа — пункт **«Сбросить демо-данные»**: удаляет
  все эксперименты, месторождения и локальные правки и создаёт их заново
  из демонстрационного набора. Действие необратимо и требует
  подтверждения в диалоговом окне.

### 2.3. Боковое меню

Слева расположена постоянная навигация:

| Пункт меню | Назначение |
|---|---|
| **Эксперименты** | Список всех экспериментов, точка входа в работу |
| **Справочник месторождений** | Управление месторождениями и минеральными профилями |
| **Дашборд** | Сводная статистика по всем экспериментам |

## 3. Основные понятия

### 3.1. Классы руды (итоговая классификация кадра)

| Класс | Значение |
|---|---|
| **Рядовая** | Обычная руда без существенных осложняющих факторов |
| **Труднообогатимая** | Руда с преобладанием тонких срастаний, усложняющих обогащение |
| **Оталькованная** | Руда с долей талька выше порога, заданного для месторождения |

Класс кадра рассчитывается автоматически на основе долей классов маски и
порога талька месторождения, но может быть скорректирован вручную (см.
[7.6](#76-панель-классификация-кадра)).

### 3.2. Классы разметки (маски) шлифа

При сегментации и ручной разметке каждый пиксель изображения относится к
одному из четырёх классов:

| Класс | Цвет на маске | Описание |
|---|---|---|
| **Обычные срастания** | 🟢 зелёный | Обычные сульфидные срастания |
| **Тонкие срастания** | 🔴 красный | Тонкие/мелкие сульфидные срастания |
| **Тальк** | 🔵 синий | Тальковые включения |
| **Нерудная матрица** | ⚪ серый | Нерудный материал (фон, вмещающая порода) |

Доля каждого класса считается от общей площади кадра, сумма долей всех
классов (включая фон/нерудную матрицу) равна 100%. Отдельно выводится
**доля сульфидов** — сумма долей обычных и тонких срастаний.

### 3.3. Порог талька

Каждому месторождению в справочнике задаётся **порог талька** — доля
талька (в процентах), при превышении которой кадр автоматически
относится к классу «Оталькованная». Порог можно менять как в карточке
месторождения, так и прямо из сводной панели эксперимента.

### 3.4. Статусы кадра

| Статус | Значение |
|---|---|
| В очереди | Кадр загружен, ожидает обработки |
| Обрабатывается | Идёт автоматическая сегментация |
| ML недоступен | Не удалось получить результат от ML-сервера |
| Ручная разметка | По кадру есть только ручная разметка, без ML |
| Обработано | Автоматическая сегментация завершена |
| Подтверждено | Пользователь утвердил класс кадра |
| Сегментация правлена | В маску внесены и сохранены ручные правки |

### 3.5. Статусы эксперимента

| Статус | Значение |
|---|---|
| Черновик | Эксперимент только создан |
| В работе | Идёт обработка/разметка кадров |
| Есть расхождения | Ручная классификация кадра расходится с расчётной |
| Завершён | Все кадры обработаны и подтверждены |
| Отчёт выгружен | По эксперименту хотя бы раз выгружен отчёт (PDF/CSV) |

## 4. Справочник месторождений

Раздел находится в боковом меню под пунктом **«Справочник
месторождений»**.

![Справочник месторождений](screenshots/02-spravochnik-mestorozhdeniy.png)

В таблице отображаются: название, код, рудный узел, порог талька,
количество минералов в профиле, балансовые запасы, статус (активно/архив)
и дата последнего изменения.

### 4.1. Создание и редактирование месторождения

1. Нажмите **«Новое месторождение»** (или значок карандаша у существующей
   строки — «Редактировать»).
2. В открывшемся диалоге заполните: название, код, порог талька, рудный
   узел, регион, типы руд, балансовые запасы, содержания металлов и
   список минералов (с ролью: сульфид / тальк / нерудная матрица /
   другое).
3. Нажмите «Сохранить».

![Диалог месторождения](screenshots/03-dialog-mestorozhdeniya.png)

### 4.2. Архивирование и удаление

- **Архивировать** — скрывает месторождение из списка активных при
  создании новых экспериментов, но сохраняет всю историю. Действие
  обратимо (кнопка «Вернуть из архива»).
- **Удалить** — доступно только для месторождений без связанных
  экспериментов. Если эксперименты есть, приложение предложит
  архивировать вместо удаления.

## 5. Создание эксперимента

Нажмите **«Новый эксперимент»** на экране «Эксперименты» или кнопку
в пустом состоянии списка.

![Новый эксперимент](screenshots/04-novyy-eksperiment.png)

### 5.1. Заполнение формы

- **Название эксперимента** — минимум 3 символа (например, «Партия 1042 —
  смена 2»).
- **Месторождение** — выбор из справочника (архивные месторождения не
  предлагаются).
- **Автор** — подставляется автоматически из поля «Автор» в верхней
  панели.

### 5.2. Загрузка изображений шлифов

- Перетащите файлы в область загрузки или нажмите на неё, чтобы выбрать
  файлы вручную.
- Поддерживаемые форматы: **PNG, JPEG, WebP**.
- Ограничения: **до 500 МБ на файл**, **до 12 кадров на эксперимент**.
- Пока файл обрабатывается браузером, на миниатюре отображается индикатор
  прогресса. Слишком крупные изображения автоматически уменьшаются до
  разрешения, поддерживаемого браузером (об этом придёт уведомление).
- Кадры можно менять местами перетаскиванием миниатюр, удалять ненужные
  и назначать **опорный кадр** (первый по порядку кадр помечается
  опорным по умолчанию).

### 5.3. Создание

После того как хотя бы один кадр обработан браузером (статус «готов»),
нажмите **«Создать эксперимент»**. Кадры автоматически ставятся в очередь
на сегментацию, и вы переходите в карточку созданного эксперимента.

## 6. Карточка эксперимента

Открывается по клику на название эксперимента в списке.

![Карточка эксперимента](screenshots/05-kartochka-eksperimenta.png)

### 6.1. Заголовок и блокировка редактирования

В заголовке — название эксперимента, месторождение, автор и текущий
статус. Если эксперимент уже открыт другим пользователем менее 5 минут
назад, показывается предупреждение с возможностью «Всё равно
редактировать» (чтобы избежать конфликтов, старайтесь не редактировать
один эксперимент одновременно с коллегами).

### 6.2. Баннер расхождений

Если у одного или нескольких кадров ручная классификация расходится с
классификацией по расчётным метрикам, наверху появляется
предупреждающий баннер с деталями.

### 6.3. Сводная панель

![Сводная панель эксперимента](screenshots/06-svodnaya-panel.png)

Показывает агрегированные метрики по всем кадрам эксперимента, текущий
порог талька месторождения (с возможностью применить новый порог,
рассчитанный по факту, к самому месторождению), а также кнопки:

- **«Завершить»** — переводит эксперимент в статус «Завершён» (доступно,
  когда все кадры обработаны и подтверждены);
- **«Перейти к отчёту»** — открывает черновик отчёта (раздел
  [8. Отчёты](#8-отчёты)).

### 6.4. Кадры эксперимента

Лента кадров показывает миниатюры со статусом каждого кадра. Клик по
миниатюре открывает [редактор кадра](#7-редактор-кадра-сегментация).
Наведите курсор на миниатюру, чтобы увидеть значок звезды в правом
нижнем углу — нажмите его, чтобы сделать кадр **опорным**. Кадры также
можно удалять из ленты.

Ниже ленты — область для добавления новых кадров в уже существующий
эксперимент (перетаскивание файлов, те же ограничения по формату и
размеру, что и при создании эксперимента).

> Перенос сегментации между кадрами (автоматический перенос разметки с
> одного кадра на другой) — экспериментальная функция, которая пока в
> разработке. Каждый кадр обрабатывается и редактируется независимо.

### 6.5. История эксперимента

В нижней части карточки — журнал действий по эксперименту (кто и когда
что сделал), отсортированный от новых записей к старым.

## 7. Редактор кадра (сегментация)

Это основной инструмент работы с разметкой. Открывается кликом по кадру
в карточке эксперимента.

![Редактор кадра — общий вид](screenshots/07-redaktor-obshchiy-vid.png)

Экран разделён на три зоны: панель инструментов слева, изображение с
маской по центру, панели легенды слоёв и классификации кадра справа.
В шапке — переключение между кадрами эксперимента стрелками, индикатор
несохранённых изменений, индикатор «Уточнение сегментации…» (когда
запрос к серверу ML ещё выполняется), кнопки «Скачать локально» и
«Сохранить изменения».

### 7.1. Панель инструментов

![Панель инструментов редактора](screenshots/08-redaktor-instrumenty.png)

| Инструмент | Клавиша | Назначение |
|---|---|---|
| Пан | `V` | Перемещение и масштабирование изображения без рисования |
| Кисть | `B` | Рисование маски произвольной формы активным классом |
| Ластик | `E` | Стирание разметки (перевод пикселей в «фон») |
| Полигон | `P` | Заливка области, заданной последовательностью точек |
| Заливка | `G` | Клик закрашивает смежную область активным классом; `Alt`+клик — удаляет разметку в области |
| Лассо | `L` | Свободная обводка области от руки с последующей заливкой/удалением; `Alt` во время обводки — удаление |

Дополнительно на панели:

- ползунок **размера кисти** (клавиши `[` / `]` — уменьшить/увеличить);
- ползунок **прозрачности слоёв маски**;
- кнопки **«Отменить»** / **«Повторить»** (`Ctrl+Z` / `Ctrl+Y`);
- кнопка **«Вернуть автосегментацию»** — откатывает все ручные правки к
  результату автоматической обработки (требует подтверждения);
- кнопка **«Очистить маску»** — полностью стирает разметку кадра
  (требует подтверждения, отменяемо кнопкой «Отменить» до сохранения);
- кнопка **«Сравнить с авторазметкой»** — временно показывает
  автоматическую маску поверх изображения вместо текущей (в т.ч.
  отредактированной) для визуального сравнения;
- переключатель **режима просмотра**: только исходное изображение /
  изображение + маска (обычный режим) / только маска.

![Режимы просмотра](screenshots/11-redaktor-rezhimy-prosmotra.png)

### 7.2. Работа с полигоном и лассо

- **Полигон**: кликами задайте вершины контура, двойной клик или клавиша
  `Enter` — замкнуть и залить область; `Esc` — отменить построение.
- **Лассо**: зажмите кнопку мыши и обведите область произвольной формой;
  отпустите кнопку — область зальётся активным классом (или очистится,
  если во время обводки был зажат `Alt`).

### 7.3. Панель «Слои маски и цвет кисти»

![Легенда слоёв](screenshots/09-redaktor-legenda-sloev.png)

Для каждого класса (Обычные срастания, Тонкие срастания, Тальк,
Нерудная матрица) доступны:

- **переключатель (радиокнопка) слева** — выбор класса, которым будет
  рисовать активный инструмент (то же самое делают клавиши `1`–`4`:
  1 — обычные срастания, 2 — тонкие срастания, 3 — тальк,
  4 — нерудная матрица);
- **флажок «показать/скрыть»** — управляет видимостью слоя на
  изображении, не влияя на саму разметку;
- цветной кружок и подпись класса;
- текущая доля класса от площади всего кадра (обновляется в реальном
  времени по мере рисования).

### 7.4. Автоматическое уточнение сегментации на сервере

Когда демо-режим **выключен** и для кадра есть привязка к серверу, при
рисовании классами «Обычные срастания» и «Тальк» приложение отправляет
штрих как подсказку (hint) на ML-сервер: тот дополняет калибровку и
пересчитывает сегментацию всего изображения, которая затем заменяет
маску в редакторе. Это происходит с небольшой задержкой после окончания
штриха, о процессе сигнализирует чип «Уточнение сегментации…» в шапке.
Инструмент «Ластик» и класс «Нерудная матрица» подсказки на сервер не
отправляют.

### 7.5. Сохранение и экспорт

- **«Сохранить изменения»** (или `Ctrl+S`) — сохраняет текущую маску
  локально, пересчитывает метрики и классификацию кадра. Кнопка активна
  только при наличии несохранённых изменений.
- При попытке уйти со страницы (закрыть вкладку, перейти к другому
  кадру или разделу) с несохранёнными изменениями появится
  диалог с выбором: «Сохранить и продолжить», «Не сохранять» или
  «Отмена».
- **«Скачать локально»** — экспортирует только вручную нарисованную
  часть разметки (без автоматической) в PNG на диск: **цветная PNG**
  (в цветах классов) или **оттенки серого** (значения — индексы
  классов). Кнопка недоступна в демо-режиме и если в кадре нет ручной
  разметки.

## 10. Демо-режим и серверный ML

Переключатель **«Демо: локальная имитация ML»** в верхней панели
определяет, откуда приложение берёт сегментацию:

| | Демо-режим включён | Демо-режим выключен |
|---|---|---|
| Источник сегментации | Локальная имитация в браузере | Серверный ML (backend по `/api/v1`) |
| Требуется запущенный backend | Нет | Да |
| Автоматическое уточнение по штрихам («Обычные срастания», «Тальк») | Недоступно | Доступно |
| Кнопка «Скачать локально» (экспорт ручной маски) | Недоступна | Доступна |
| Подходит для | Демонстраций, работы без сервера | Реальной работы с полноценной ML-сегментацией |

Если backend недоступен при выключенном демо-режиме, кадру присваивается
статус «ML недоступен», а редактор продолжает работать в режиме ручной
разметки.

## 11. Частые вопросы и устранение неполадок

**Кадр получил статус «ML недоступен» — что делать?**
Проверьте, что сервер ML запущен и доступен, либо временно включите
демо-режим. Кадр можно размечать вручную независимо от статуса ML.

**Пропали изменения после закрытия вкладки.**
Приложение предупреждает о несохранённых изменениях диалогом при
закрытии/обновлении страницы и при переходе между кадрами внутри
приложения — не игнорируйте это предупреждение и нажимайте «Сохранить»
перед уходом со страницы.

**Нужно начать всё заново для демонстрации.**
Используйте пункт меню **«Сбросить демо-данные»** в верхней панели.
Помните: действие необратимо и удаляет реальные данные, если они не
являются частью демо-набора.

**Данные не видны на другом компьютере/в другом браузере.**
Это ожидаемое поведение прототипа: все данные хранятся локально в
браузере (IndexedDB), общего сервера хранения нет. Используйте экспорт
(PDF/CSV, скачивание маски) для переноса результатов.

**Нельзя удалить месторождение.**
Если у месторождения есть связанные эксперименты, удаление заблокировано
— используйте архивирование вместо удаления.

**Не работает кнопка «Скачать локально» в редакторе.**
Кнопка недоступна в демо-режиме и если в кадре нет собственноручно
нарисованной разметки (только автоматическая сегментация не считается).

### 12.2. Глоссарий

| Термин | Значение |
|---|---|
| **OM-шлиф** | Оптическое (микроскопическое) изображение полированного шлифа руды |
| **Кадр** | Одно загруженное изображение (панорама шлифа) внутри эксперимента |
| **Эксперимент** | Набор кадров одного месторождения, обрабатываемых и классифицируемых вместе |
| **Маска** | Разметка изображения по классам (попиксельная принадлежность к классу) |
| **Опорный кадр** | Кадр, отмеченный как основной/эталонный в эксперименте |
| **Доля талька** | Процент площади кадра, отнесённой к классу «Тальк» |
| **Порог талька** | Настраиваемое значение доли талька, при превышении которого кадр относится к классу «Оталькованная» |
| **Ручная разметка / ручная правка** | Изменения маски, внесённые пользователем поверх или вместо автоматической сегментации |
| **Авторазметка / автомаска** | Результат автоматической сегментации (ML или демо-имитация), до ручных правок |
| **Расхождение** | Несовпадение ручного класса кадра с классом, рассчитанным по метрикам |
| **Хинт (подсказка)** | Штрих ручной разметки, отправляемый на сервер ML для уточнения калибровки сегментации |
